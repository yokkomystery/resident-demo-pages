GitHub Pagesで
HTMLを公開する手順

ターミナルやプログラムは使いません。GitHubの画面をクリックして、 手元のHTMLファイルをインターネット上に無料公開する方法です。

全体の流れ

  1. HTMLファイルの名前を「index.html」にする
  2. GitHubにログインする
  3. 公開用の置き場所を作る
  4. HTMLファイルをアップロードする
  5. GitHub Pagesを有効にする
  6. 表示されたURLを開く
所要時間の目安は5〜10分です。GitHubアカウントを持っていない場合は、 最初に無料アカウントを作成してください。
1

ファイル名を「index.html」にする

Finderで、公開したいHTMLファイルがあるフォルダを開きます。

今回は resident.html を選択し、コピーを作って、 コピーしたファイルの名前を index.html に変更します。

  1. resident.html を右クリックする
  2. 「複製」をクリックする
  3. 複製したファイルを右クリックして「名前を変更」をクリックする
  4. 名前を index.html にする

「拡張子を変更してもよろしいですか？」と表示された場合は、 “.html”を使用を選びます。

元の resident.html は残しておきます。 GitHub Pagesは index.html を最初のページとして表示します。
2

GitHubにログイン

  1. ブラウザで https://github.com/ を開く
  2. 右上の Sign in をクリックする
  3. メールアドレスまたはユーザー名と、パスワードを入力する
  4. Sign in をクリックする
アカウントがない場合は Sign up から無料で作成できます。
3

公開用の置き場所を作る

GitHubでは、ファイルの置き場所を「リポジトリ」と呼びます。

  1. GitHub画面の右上にある ＋ をクリックする
  2. New repository をクリックする
  3. Repository name に名前を入力する
    例：resident-demo-pages
  4. Public を選ぶ
  5. Add a README file などのチェックは付けなくてよい
  6. 一番下の Create repository をクリックする
リポジトリ名には、半角英数字とハイフンを使うと分かりやすくなります。 日本語や空白は避けてください。
4

HTMLファイルをアップロード

  1. 作成後の画面にある uploading an existing file をクリックする
  2. Finderから index.html を点線の枠内へ ドラッグ＆ドロップする
  3. ファイル名が表示されるまで待つ
  4. 画面下部の Commit changes をクリックする
CSS、画像、JavaScriptなど別のファイルも使っている場合は、 それらも一緒にドラッグ＆ドロップします。今回の resident.html は単体でアップロードできます。
5

GitHub Pagesを有効化

  1. リポジトリ上部の Settings をクリックする
  2. 左側メニューの Pages をクリックする
  3. Build and deployment の Source で Deploy from a branch を選ぶ
  4. Branch の左側を main、 右側を /(root) にする
  5. Save をクリックする
Settings が見つからない場合は、上部メニュー右端の … の中を確認してください。
6

公開URLを開く

  1. 設定後、1〜3分ほど待つ
  2. ブラウザの再読み込みボタンを押す
  3. Pages設定画面上部の Your site is live at に続くURLを確認する
  4. Visit site をクリックする

公開URLは通常、次の形になります。

https://ユーザー名.github.io/リポジトリ名/
最初に「404」と表示されても、設定直後なら異常とは限りません。 2〜3分待ってから再読み込みしてください。

今回の公開結果

  • 公開ページ: https://yokkomystery.github.io/resident-demo-pages/
  • GitHubリポジトリ: https://github.com/yokkomystery/resident-demo-pages

HTMLを更新するとき

  1. GitHubで対象のリポジトリを開く
  2. Add file → Upload files をクリックする
  3. 新しい index.html をドラッグ＆ドロップする
  4. Commit changes をクリックする
  5. 1〜3分待って公開ページを再読み込みする
同じ名前の index.html をアップロードすると、 古い内容が新しい内容に更新されます。
